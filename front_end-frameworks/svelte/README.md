# Agentic AI avec Svelte

Migration en Svelte 5 de l'application Agentic AI réalisée initialement avec React, puis avec Vue.js.

## Installation

```bash
npm install
npm run dev
```

## Vérifications

```bash
npm run lint
npm run build
```

## Déploiement GitHub Pages

```bash
npm run deploy
```

Le projet utilise Svelte 5, Vite, JavaScript, Tailwind CSS et `@lucide/svelte`.
